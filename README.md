## ?? Key Features
- **Mobile-First UX:** Ultra-fast loading, 1-tap Call and WhatsApp actions on mobile, sticky action bar, responsive drawer menu.
- **Direct WhatsApp Booking Engine:** Generates structured, pre-filled WhatsApp messages with passenger details, pickup, drop, trip type, date, and time.
- **Ertiga MPV Showcase:** Features Maruti Suzuki Ertiga with family-friendly seating, air conditioning, and interactive photo uploader for previewing real vehicle photos.
- **Service Offerings:** Local Cab, Outstation, Airport Pickup & Drop, One Way Trip, Round Trip, and Custom Cab Booking.
- **Tamil Nadu Coverage & Map:** Highlights key destinations (Chennai, Madurai, Trichy, Salem, Erode, Tiruppur, Ooty, Pollachi, etc.) with embedded Google Maps location.
- **Verified & Trustworthy Content:** Strictly clean copy with no fake reviews, inflated claims, or unsupported promises.
